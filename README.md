# Ma Belle Semaine — V2.0

Base Flutter de l'application de coach hebdomadaire pour la retraite.

## Nouveautés V2
- fiches activités réellement paramétrables : catégorie, emoji, durée, fréquence, priorité, jours préférés ;
- filtres par catégorie ;
- ajout, modification et suppression d'activités ;
- génération automatique d'une semaine avec recherche d'équilibre ;
- bouton « Repenser » / réorganisation du planning ;
- validation d'une activité avec durée réellement réalisée et ressenti ;
- premier historique de séances en mémoire ;
- premier moteur de message du coach basé sur les activités réalisées ;
- accueil plus vivant et planning mis en évidence sur le jour courant ;
- version affichée : V2.0.

## Lancer
```bash
flutter pub get
flutter run -d chrome
```

## Étape suivante prévue
V3 : séparation des objectifs (sport, plaisir, culture, social, sorties), contraintes de rythme, journal du coach, statistiques semaine réalisée/prévue et persistance locale.
